# StepDaddy Gateway 3.0.31

versionCode: 30031

## Highlights

- **Smarter backup matching** — Merge fallbacks / skip-dupes use a region- and language-aware score (threshold 70). Stops common false consolidations (ESPN vs ESPN Deportes, BBC One vs BBC News, US vs UK, CNN vs CNN Türk).
- **Channel backups editor** — Settings → Channel backups… to fix attachments: remove, block auto-rematch, accept/reject suggestions, or pick a supplement manually. Corrections survive refresh.
- Full catalog remains the default import mode.

See `docs/CHANNEL-BACKUPS.md` and `CHANGELOG.md`.
