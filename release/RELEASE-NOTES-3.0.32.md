# StepDaddy Gateway 3.0.32

versionCode: 30032

## Highlights

- **Default = Merge fallbacks** — Free-TV, iptv-org, ntv, dulo, and Adult Swim now default to smart consolidate (high-confidence score ≥70 only). Multiple perfect matches still attach as backups on one Daddy channel.
- **Upgrade migration** — installs still on the old Full-catalog default (never customized) flip to Merge fallbacks. If you already chose Full catalog / Skip / Merge in Settings, that choice is kept.
- **Revert** — Settings → provider → **All channels** → Save.
- **Fix mistakes** — Settings → Channel backups… to remove or block a bad auto-match.
- Soft health note: `Backups: auto · N channels` when backups are attached.

See `docs/CHANNEL-BACKUPS.md` and `CHANGELOG.md`.
